Игровые ассеты находятся в `main-character/`: 19 фотореалистичных PNG 2048×2048 и WebP с alpha, исходный референс, запросы генерации и общий лист сравнения.
Manifest: `js/character-states.js`. Инструкции по замене и все описания: `CHARACTER_ASSETS.md` в корне проекта. Для просмотра отдельных поз откройте `character-preview.html`.
Старые файлы `character-*.webp` в этой папке — архивные нейтральные заглушки; игра их больше не использует.
